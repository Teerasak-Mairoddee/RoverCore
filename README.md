# RoverCore

An educational Unity 6 simulation of an autonomous ground rover: occupancy-grid mapping, custom A* pathfinding, waypoint following, raycast sensing and dynamic replanning.

> **Status:** early setup (Milestone 0). Nothing below the plan is implemented yet. RoverCore is a simulator; nothing here is validated for real-world robot control.

## Requirements

- Unity **6000.6.5f1** (Universal Render Pipeline)
- Visual Studio 2022 or later with the Unity workload
